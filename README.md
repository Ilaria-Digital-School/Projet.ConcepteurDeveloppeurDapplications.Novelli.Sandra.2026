**🍝 CUCINA 🍝**


A collaborative cooking website where users can browse a large collection of recipes, filter them to find exactly what they're craving, and share their own creations with the community.


FEATURES

Browse recipes — explore a large library of recipes on the homepage.
Filter recipes — use the filter menu on the left side of the homepage to narrow results by category, ingredient, or other criteria.
Favourites — registered users can save recipes to a favourites list, accessible anytime via the *Favourites ❤️* button in the navigation menu.
Share your own recipes — registered users can add their own recipes to the collection for others to discover.


TECH STACKS

HTML — page structure and markup
CSS — styling and layout
JavaScript — interactivity and dynamic behaviour


GETTING STARTED

This project was built using Visual Studio Code (v1.129.1).


PREREQUISITES

A modern web browser (Firefox, Chrome, Edge, etc.)
Visual Studio Code or another code editor (optional, for development only)


RUNNING THE PROJECT: clone or download this repository.

Clone:

bash -> git clone <repository-url>


Navigate into the project folder:

bash -> cd cucina

Open index.html in your browser, or use a live server extension in your editor for auto-reloading.


USAGE

Viewers can browse the full list of recipes and apply filters from the left-hand menu on the homepage.
Registered users can additionally:

Save recipes to their favourites list (view via the *Favourites ❤️* nav button)
Submit and manage their own recipes
